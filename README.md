# Hola Mundo Android

Primera aplicación Android desarrollada para la Actividad 4:
Configurando un IDE y GitHub – App Hola Mundo.

## Autor

Diego Fernando Ardila Mora
Universidad Manuela Beltrán
Ingeniería de Software

## Descripción

La aplicación muestra el saludo “¡Hola Mundo!”, el texto
“Mi primera aplicación Android” y el nombre del autor.

## Herramientas utilizadas

- Android Studio Rabbit 2 | 2026.2.2.
- Kotlin y Jetpack Compose.
- Android SDK.
- Gradle con archivos de configuración Kotlin DSL.
- Git y GitHub.

## Compatibilidad y ejecución

- Versión mínima: Android 7.0 (API 24).
- Ejecutada en un Motorola moto g85 5G mediante depuración USB.

## Cómo ejecutar el proyecto

1. Clonar el repositorio o descargarlo.
2. Abrir la carpeta del proyecto en Android Studio.
3. Esperar la sincronización de Gradle e instalar los componentes
   del SDK que solicite el IDE.
4. Conectar un celular compatible con depuración USB habilitada
   o configurar un emulador.
5. Seleccionar el dispositivo y pulsar Run.

## Archivos principales

- MainActivity.kt: actividad inicial e interfaz con Compose.
- AndroidManifest.xml: configuración de la aplicación.
- app/src/main/res/: recursos de la aplicación.
- build.gradle.kts: configuración de compilación.
